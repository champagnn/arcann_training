# Authors and contributors

ArcaNN is developed in the Theoretical Chemistry Group at ENS (Paris). The code was first hosted in the `arcann-chem` GitHub organization and is now hosted at [champagnn/arcann_training](https://github.com/champagnn/arcann_training).

GitHub's contributor list only shows people whose commits are linked to a GitHub account. This file is the full record.

## Adding yourself

If you contribute to ArcaNN, add your name (and GitHub handle) to the Contributors section in your pull request. For how contributors become authors of the software citation, see [Authorship and credit](https://champagnn.github.io/arcann_training/contributions/contributions/#authorship-and-credit).

For citation, see the [documentation](https://champagnn.github.io/arcann_training/). Funding and acknowledgments are listed in [docs/project_details](docs/project_details/).
